# Audios · Historias cortas en inglés

Audios de las 30 historias del libro *Historias cortas en inglés*, de Nora Corbin.

Cada historia tiene dos pistas: una a velocidad lenta, para seguir el texto, y otra
a velocidad normal.

Se escuchan aquí, sin registro y sin coste:
**https://alemandesdecero.github.io/misterios**
